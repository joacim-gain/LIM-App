Site: Floor, zone details and Link Activity

The viewer starts on a floor, opens a zone to read its details and linked activities, and switches to the edit view to draw a zone and link activities to it. The Link Activity panel is the same component in the read-only Activity tab and in the edit view.

Rules

RuleBehaviour
LinkingCheckbox links / unlinks a row; the header checkbox does all visible rows. The count badge shows linked activities.
Crosses the zoneAn activity whose dates start before or end after the zone dates. Its timeline bar gets an orange outline; the drawer explains why.
Lock zone durationWhen on (edit form), activities that cross the zone can't be linked: greyed rows, footer note “Lock zone duration is on · N can't be linked”.
Save (Activity tab)Disabled until a link changes. Save keeps the current links; Reset returns to the last save.
Reset (edit view)Returns the links to the state the view opened with.
FilterStart / End date, Filter for this floor, Site, Building, Floor, Organization (multi), Discipline, Zone. Apply is disabled until something changes.
Zone datesStart, Duration and End stay in sync; changing them re-checks which activities cross the zone.
ShapesSingle Shape: a new drag replaces the shape. Multi Shape: each drag adds one. Esc hides the shape being drawn.

Implementation

The whole demo is one file, site/index.html. The view is a data attribute on .app; CSS shows and hides parts per view, so the Link Activity panel is never duplicated.

View switching (JS)
// .app[data-view="floor" | "site" | "edit"][data-tab="details" | "activity"]
go('site', zoneId)   // open Site details for a zone (panel 300 px, Details tab)
go('edit', zoneId)   // Edit Zone (name filled in); go('edit') = Add Zone
go('floor')          // back to Floor; closes the drawer, filter and menus
setTab('activity')   // Details | Activity inside Site details
Panel parts per view (CSS)
.app[data-view="floor"] .dock { display: none; }                 /* no panel on Floor */
.app[data-view="site"] .d-head { display: none; }                /* zone header + tabs instead */
.app[data-view="edit"] .z-head, .app[data-view="edit"] .z-tabs { display: none; }
.app[data-view="site"][data-tab="details"] .d-table { display: none; }

Notes

  • No backend. Links, Save and the zone form live in the page; reloading resets them.
  • Visual only for now: the other Floor strip icons, zone row ⋮ menus, Unlink Activity, Take a Note, and most ribbon tools (period, Group, Sort, Level, View, Import, Legends, Refresh). Search, filter, the switches and ⋯ work.
  • Zone dates on Details show the dates the Activity tab checks against (02.09.2026 – 31.03.2027), not the Figma placeholder.
  • Zone shapes are part of the floor plan image; transparent buttons sit over them.
