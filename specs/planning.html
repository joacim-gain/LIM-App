Planning: Gantt and the single-row ribbon

The Settings drawer is gone. Every view setting now lives in one ribbon row above the Gantt. When the screen narrows, sections fold into named buttons, labels give way to icons, and whatever still doesn't fit moves into ⋯.

Ribbon

One 64 px row that fills the width. Sections are divided by lines only. Wide screens show Time, Sort and Group as inline picks; narrower screens fold them into a named button with a menu.

Fitting

The ribbon re-fits on every resize and once fonts have loaded (icon names measure wide until Material Icons arrives). Three passes run until the row fits:

1Fold sectionsOpen sections fold into their named button in this order: Group, Time, Level, Sort, Display, View, Search.
2Labels → iconsNamed buttons lose their labels, right to left.
3Into ⋯Whole sections move into ⋯, right to left. ⋯ lists them in ribbon order with dividers.
assets/js/ribbon-single.js · fit()
const FOLD_ORDER = ['group', 'time', 'level', 'sort', 'display', 'view', 'find'];
// 1 · open sections fold into their named button, in FOLD_ORDER
for (const name of FOLD_ORDER) { if (!over()) break; /* fold section */ }
// 2 · labels give way to icons, right to left
for (let i = gs.length - 1; i >= 0 && over(); i--) { /* icon only */ }
// 3 · sections move into ⋯, right to left
for (let i = gs.length - 1; i > 0 && over(); i--) { /* hide, add to ⋯ */ }
  • Search box: an open search field (while typing) stays open during fitting.
  • Dividers show only between two visible sections.
  • ⋯ menu: 240 px, right-aligned, 32 px rows with icon + label, toggles show a check; Figma “Pop-up · More (⋯)”.
