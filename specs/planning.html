Planning: Gantt and the ribbon (v4)

The Settings drawer is gone. Every view setting lives in one ribbon row above the Gantt, in two styles: Detailed (default, 64 px tiles) and Single line (48 px icons), switched by the Compact toggle. When the screen narrows, tools form groups (Others ▾, Display ▾, View ▾); at 1350 px and below Search and Time collapse; then labels give way to icons.

Fitting

The ribbon re-fits on every resize and once fonts have loaded. Steps run in order until the row fits; nothing that has folded comes back on a smaller screen.

1Group chips → Group ▾Detailed. Single line: the names beside the icons go first, right to left.
2Others ▾Takes Updated, Refresh, Legends, then Set default.
3Display ▾Active tasks, Zoom, Compact.
4View ▾The view modes fold in.
5Sort chips → Sort ▾Detailed, below ≈1440 px.
6Level + Display → View ▾Together, before Time and Search collapse.
7≤1350 pxSearch becomes a button; Time becomes one Monthly ▾ (steps 1–6 forced).
8Labels → iconsRight to left; last, sections move into Others ▾.
  • Search box is a fixed 320 px; it never stretches.
  • Spacing: one gap everywhere — between tools, on both sides of every divider (Search included) and around the dividers inside View modes and Display; it is worked out per width after fitting (minimum 6 px). Detailed dividers are 48 px, single-line 16 px.
  • Pop-ups open 4 px below their button and stay on screen.

Notes

  • No backend. Settings and edits live in localStorage; avatar → Reset demo data restores everything.
  • Sample data follows the live app recording; some cut-off names were completed (marked // completed in data.js).
  • Import only opens the file picker.
  • Legend labels use the Figma text (“Logistics Volume - Normal / Critical”); the live app says “High / Low”.
